# WinKit 功能清单

★ = 第一版就做　☆ = 后面再加

---

## 一、系统维护

**总览**
- ★ 实时性能曲线（CPU、内存、磁盘读写、网络上下行）
- ★ 系统信息卡（系统版本、CPU、内存、显卡、主板、开机时长）
- ★ 一键体检：只扫描不动手，告诉你哪里有问题

**进程**
- ★ 进程列表：搜索、排序、按父子关系看树形
- ★ 结束进程（可连整个进程树一起结束）
- ★ 看到进程的路径、命令行、启动时间
- ☆ 挂起 / 恢复进程
- ☆ 进程详情：打开了哪些文件、加载了哪些模块
- ☆ 数字签名校验（标出没签名的可疑程序）

**开机启动**
- ☆ 管理开机自启项：注册表启动项、启动文件夹、计划任务、自启服务
- ☆ 一键禁用 / 恢复（只禁用不删除，随时能还原）

**服务**
- ☆ 查看和修改服务启动类型（自动 / 手动 / 禁用）、手动启停

**磁盘**
- ★ 各分区容量总览，空间不足时提醒
- ☆ 磁盘空间可视化：像地图一样看哪个文件夹最占地方，一层层钻进去
- ☆ 找大文件（超过指定大小）
- ☆ 找重复文件（按内容比对，不是按文件名）
- ☆ 找空文件夹、0 字节文件
- ☆ 磁盘健康（SMART：通电时间、坏道、剩余寿命）—— 部分硬盘读不到

**垃圾清理**
- ★ 清理：用户临时文件、系统临时文件、应用崩溃转储、系统小型转储、Windows 错误报告缓存、DirectX 着色器缓存
- ★ 每一项都写清楚"这是什么、清了有什么影响"
- ★ 清之前先列出要删的东西给你看，可以逐项取消
- ★ 三种处置方式可选：**隔离区（默认，100% 可一键撤销）** / Windows 回收站 / 彻底删除（两道确认）
- ★ 单独一个"清空回收站"按钮
- ★ 危险操作带确认框，默认按钮是"取消"
- ☆ 进阶清理（Windows 更新缓存等），默认关闭，需要手动打开
- ☆ 白名单：指定目录永不清理
- ☆ 按目录自定义清理规则（当前是内置规则库）

> 说明：**缩略图缓存**与 **Prefetch** 是刻意不做的 —— 前者在 Explorer 运行时基本都被占用、成功率极低，
> 后者清了反而会让下次启动变慢。宁可少列一条，也不做会让人误以为"工具坏了"的功能。

## 二、文件与批量处理

- ☆ 批量重命名：正则替换、加序号、改大小写、删空格、按修改日期重命名，改之前实时预览
- ☆ 批量重命名支持整批撤销
- ☆ 按规则自动整理文件：按类型 / 日期 / 大小 / 关键字归档到对应文件夹
- ☆ 文件哈希计算（单个或批量），可导出校验清单、批量比对
- ☆ 图片批量处理：格式转换、缩放、压缩、看 EXIF
- ☆ 视频音频转码（需要电脑上装过 ffmpeg，不内置）
- ☆ 批量修改文件属性、时间戳
- ☆ 按关键字搜索文件内容

## 三、开发 / 运维辅助

- ☆ 端口占用查询：查某端口被谁占了，一键结束
- ☆ 列出本机所有监听端口
- ☆ hosts 文件编辑器：语法高亮、分组、一键启用/禁用某行、改完顺便测一下域名解析
- ☆ hosts 自动备份 + 一键还原
- ☆ 环境变量编辑器：用户级 / 系统级，PATH 按行可视化编辑
- ☆ PATH 检查：找出重复项、失效路径、过长警告
- ☆ 全局命令面板（Ctrl+K）：搜功能、搜路径、搜进程，回车直达
- ☆ 日志实时跟踪：像 tail -f 一样看日志，支持关键字过滤和高亮
- ☆ 自动识别日志编码（UTF-8 / GBK 不乱码）
- ☆ 常用工具启动面板：自定义常用命令、程序、网址，一键打开
- ☆ 小工具集合：JSON 格式化、正则测试、Base64、URL 编解码、时间戳转换、UUID
- ☆ 网络诊断：ping、DNS 查询、路由追踪、端口连通性测试
- ☆「导出为命令」：把当前操作导出成等价的 PowerShell 命令，方便审计和自己复核

## 四、硬件与系统信息

- ☆ 硬件详情：CPU 规格、每根内存条的容量频率厂商、显卡、主板、BIOS、硬盘、网卡、电池
- ☆ 网络连接列表：哪个程序连了哪个地址
- ☆ 网络流量监控：各网卡实时上下行速率、累计流量
- ☆ 网速悬浮窗：桌面置顶小窗显示网速
- ☆ CPU / 显卡温度、风扇转速 —— 很多机器读不到，不保证
- ☆ 显卡占用率（N 卡支持较好）

## 五、界面与通用功能

- ★ 左边导航分类 + 右边内容区，不用记命令
- ★ 深色 / 浅色主题
- ★ 危险操作先预览、再确认、可撤销
- ★ 撤销中心：查看历史操作，一键回滚
- ★ 操作日志：每次做了什么都有记录
- ★ 管理员权限按需申请（按钮上带盾牌图标，点它才提权）
- ★ 免安装：双击即用，配置跟着程序走，卸载 = 删文件夹
- ★ 默认不联网、不上传任何数据；AI 助手为**可选启用**，且每次发送前先显示将要发送的确切内容
- ☆ 只读审计模式：一键禁用所有写操作，只允许扫描和导出
- ☆ 最小化到托盘
- ☆ 只允许开一个窗口（重复启动会唤起已有窗口）
- ☆ 配置一键导入 / 导出（换电脑迁移）
- ☆ 崩溃自动记录日志到本地
- ☆ 英文界面

## 六、明确不做的功能

- 一键加速、内存释放 —— 效果存疑甚至反效果
- 注册表深度优化 —— 不可解释、不可回滚
- 驱动级操作、磁盘底层修复
- 联网云查杀、账号系统、数据上报
- 绕过 UAC、开机常驻
- 磁盘跑分测试
